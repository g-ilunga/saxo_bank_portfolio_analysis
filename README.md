# saxo_bank_portfolio_analysis
The purpose of this project was to analyse the sectoral and geographical allocation of my Saxo Bank portfolio. The idea came after realising that the Saxo platform offered limited insight into portfolio exposure, particularly when it comes to ETFs.

In this repository I included the full script I developed to achieve the purpose of this project. I wrote a series of articles on Medium to explains the full process of building this script. The articles are listed below:
